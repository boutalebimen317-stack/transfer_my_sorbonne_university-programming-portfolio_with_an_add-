
# Recruitment Database System

## About the Project

A relational database designed to manage recruitment activities. It stores information about companies, candidates, job opportunities and applications.

The project uses PostgreSQL to organize recruitment data and retrieve useful information through SQL queries.

## Features

- Register companies.
- Store candidate profiles and skills.
- Manage job offers and salaries.
- Track candidate applications.
- Update application statuses.
- Count applications for each job.
- Retrieve recruitment statistics.

## Technologies Used

- PostgreSQL 17
- SQL
- pgAdmin 4
- Visual Studio Code
- SQLTools

## Database Concepts

- Relational database design.
- Primary and foreign keys.
- One-to-many relationships.
- JOIN operations.
- Aggregate functions.
- GROUP BY and WHERE.
- Constraints and data validation.

## How to Run

1. Connect to PostgreSQL using SQLTools or pgAdmin.
2. Execute `setup.sql` to create the tables and insert sample data.
3. Execute `queries.sql` to explore the database.

## Project Status

First version completed. The database uses sample recruitment records and can be extended with additional features.
