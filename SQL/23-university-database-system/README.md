
# University Database System

## About the Project

A relational database designed to organize basic university information, including students, departments, courses and student enrollments.

The project uses PostgreSQL to store information and retrieve it through SQL queries.

## Features

- Store student information.
- Organize academic departments.
- Manage university courses.
- Register students in courses.
- Record and update grades.
- Calculate student average grades.
- Display department statistics.

## Technologies Used

- PostgreSQL 17
- SQL
- pgAdmin 4
- Visual Studio Code
- SQLTools extension

## Database Concepts

- Primary and foreign keys.
- Relational database design.
- One-to-many relationships.
- JOIN operations.
- Aggregate functions.
- GROUP BY and ORDER BY.
- Constraints and data validation.

## How to Run

1. Open PostgreSQL using SQLTools or pgAdmin.
2. Execute `setup.sql` to create the schema, tables and sample data.
3. Execute `queries.sql` to explore and modify the database.

## Project Status

First version completed. The database contains sample university records and can be extended with additional tables and features.
