
# Task Scheduling Application

## About the Project

A small task planner built with JavaScript. It helps users organize their daily activities, set deadlines and keep track of completed work.

## Features

- Add tasks with a deadline.
- Choose between three priority levels.
- Mark tasks as completed or undo them.
- Delete tasks.
- Filter tasks by status.
- View task statistics.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Visual Studio Code

## Programming Concepts

- Arrays and objects.
- Functions.
- DOM manipulation.
- Event listeners.
- Array methods (filter and forEach).
- Conditional statements.

## How to Run

1. Open the project folder in Visual Studio Code.
2. Open `index.html` in your browser, or use Live Server.
3. Start adding tasks.

## Project Status

First version completed. Tasks are stored in memory and reset when the page is refreshed. Local storage could be added in a future update.
