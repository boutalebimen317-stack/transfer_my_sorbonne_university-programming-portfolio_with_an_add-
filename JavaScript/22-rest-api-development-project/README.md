
# REST API Development Project

## About the Project

A simple REST API built with JavaScript and Node.js to manage a collection of tasks.

The API allows clients to retrieve tasks, add new ones, update existing tasks and delete them through HTTP requests.

## Features

- Retrieve all tasks.
- Find a task using its ID.
- Add new tasks.
- Update task information.
- Delete tasks.
- Validate incoming data.
- Return appropriate HTTP status codes.

## Technologies Used

- JavaScript
- Node.js
- HTTP module
- Visual Studio Code

## Programming Concepts

- REST API fundamentals.
- HTTP methods (GET, POST, PUT, DELETE).
- JSON data.
- Arrays and objects.
- Asynchronous programming.
- Request and response handling.

## How to Run

1. Open the project folder in your terminal.
2. Start the server:

   Windows and macOS:

   `node server.js`

3. Open another terminal and test the API using PowerShell or an API testing tool.

## Project Status

First version completed. Data is stored in memory, so tasks reset when the server restarts. Database storage may be added later.
