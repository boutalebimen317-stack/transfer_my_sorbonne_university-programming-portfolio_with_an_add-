# Interactive Quiz Application

## About the Project

This is a beginner-level JavaScript project designed to create an interactive quiz application.

Users can answer multiple-choice questions, receive instant feedback, track their scores, and restart the quiz.

## Features

- Display multiple-choice questions.
- Select answers interactively.
- Check answers automatically.
- Highlight correct and incorrect answers.
- Display feedback after each answer.
- Calculate the final score.
- Restart the quiz.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Visual Studio Code

## Programming Concepts

- Arrays and objects
- Variables
- Functions
- Conditional statements
- Loops and array methods
- DOM manipulation
- Event listeners
- Dynamic HTML elements

## How to Run

1. Open the project folder.
2. Open `index.html` in a web browser.
3. Alternatively, use the Live Server extension in Visual Studio Code.
