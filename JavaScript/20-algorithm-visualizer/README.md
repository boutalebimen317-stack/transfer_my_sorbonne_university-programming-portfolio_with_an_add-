# Algorithm Visualizer

## About the Project

Algorithm Visualizer is a JavaScript project that explores how sorting algorithms work through interactive visualizations.

It transforms an array of numerical values into animated bars, allowing users to follow the sorting process step by step. Each operation is displayed visually, making it easier to understand how elements are compared, moved, and arranged.

## Features

- Generate random arrays to experiment with different input sequences.
- Visualize Bubble Sort, Selection Sort, and Insertion Sort.
- Adjust animation speed to control the visualization.
- Track the number of comparisons and swaps.
- Highlight elements as they are processed.
- Follow the sorting process until the array is fully organized.

## How to Run

1. Clone or download the repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser.
4. Alternatively, use the Live Server extension for a local development environment.
