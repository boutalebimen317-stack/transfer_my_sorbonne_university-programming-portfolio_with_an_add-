# AI Text Classification System

## About the Project

This is a beginner-level Python project designed to classify text into different categories using keyword matching.

The program analyzes a sentence, compares its words with predefined keywords, calculates category scores, and predicts the most relevant category.

## Features

- Accept text from the user.
- Analyze text using predefined keywords.
- Classify text into Technology, Sports, or Entertainment.
- Calculate scores for each category.
- Display the predicted category.
- Handle empty input and unknown text.

## Technologies Used

- Python 3
- Visual Studio Code

## Programming Concepts

- Dictionaries
- Lists
- Functions
- Loops
- Conditional statements
- String processing
- Basic text classification

## How to Run

1. Open the project folder in your terminal.
2. Run the program:

   Windows and macOS:
   `python main.py`
