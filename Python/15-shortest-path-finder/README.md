# Shortest Path Finder

## About the Project

This is a beginner-level Python project designed to find the shortest route between two locations in a graph.

The program uses Dijkstra's Algorithm to calculate the shortest distance and display the best route between a starting point and a destination.

## Features

- Store locations and their connections.
- Assign distances between connected locations.
- Choose a starting location and destination.
- Find the shortest route automatically.
- Calculate the total distance.
- Detect invalid or unreachable locations.

## Technologies Used

- Python 3
- Visual Studio Code

## Programming Concepts

- Dictionaries
- Sets
- Functions
- Loops
- Conditional statements
- Graphs
- Dijkstra's Algorithm

## How to Run

1. Open the project folder in your terminal.
2. Run the program:

   `python main.py`
