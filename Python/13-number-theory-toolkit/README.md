# Number Theory Toolkit

## About the Project

This is a beginner-level Python project designed to perform common mathematical operations related to number theory.

The program allows users to check prime numbers, calculate GCD and LCM, find factorials, and display the divisors of a number.

## Features

- Check whether a number is prime.
- Calculate the Greatest Common Divisor (GCD).
- Calculate the Least Common Multiple (LCM).
- Calculate the factorial of a number.
- Find all divisors of a number.
- Interactive menu for choosing operations.

## Technologies Used

- Python 3
- Visual Studio Code

## Programming Concepts

- Functions
- Loops
- Conditional statements
- Lists
- User input
- Mathematical operations
- The Euclidean algorithm

## How to Run

1. Open the project folder in your terminal.
2. Run the program:

   Windows and macOS:
   `python main.py`
