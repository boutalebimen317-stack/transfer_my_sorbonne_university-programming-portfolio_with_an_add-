# CV Matching Prototype

## About the Project

This is a beginner-level Python project designed to compare a candidate's skills with the requirements of a job position.

The program analyzes the candidate's skills, identifies matching and missing skills, calculates a matching percentage, and provides a simple recruitment recommendation.

## Features

- Display the required job skills.
- Enter a candidate's name and skills.
- Compare candidate skills with job requirements.
- Identify matching skills.
- Identify missing skills.
- Calculate the matching percentage.
- Provide a simple recruitment recommendation.

## Technologies Used

- Python 3
- Visual Studio Code

## Programming Concepts

- Lists
- Functions
- Loops
- Conditional statements
- String methods
- Percentage calculations
- Basic data analysis

## How to Run

1. Open the project folder in your terminal.
2. Run the program:

   Windows and macOS:
   `python main.py`
