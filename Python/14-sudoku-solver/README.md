# Sudoku Solver

## About the Project

This is a beginner-level Python project designed to solve Sudoku puzzles automatically.

The program uses a backtracking algorithm to find the correct numbers for empty cells while respecting Sudoku rules.

## Features

- Display the original Sudoku puzzle.
- Find empty cells automatically.
- Check whether a number can be placed in a specific cell.
- Solve the puzzle using backtracking.
- Display the completed Sudoku grid.
- Detect when no solution is found.

## Technologies Used

- Python 3
- Visual Studio Code

## Programming Concepts

- Functions
- Nested loops
- Lists and 2D arrays
- Conditional statements
- Recursion
- Backtracking algorithm

## How to Run

1. Open the project folder in your terminal.
2. Run the program:

   Windows and macOS:
   `python main.py`
