# Intelligent Recommendation System

## About the Project

This is a beginner-level Python project designed to recommend movies based on a user's interests and favorite genres.

The system compares user preferences with movie information, calculates matching scores, and displays recommendations from the highest score to the lowest.

## Features

- Display available movie genres and interests.
- Enter personal preferences.
- Compare preferences with movie information.
- Calculate recommendation scores.
- Sort movies based on matching scores.
- Display personalized movie recommendations.

## Technologies Used

- Python 3
- Visual Studio Code

## Programming Concepts

- Lists and dictionaries
- Functions
- Loops
- Conditional statements
- String methods
- List comprehensions
- Sorting
- Basic recommendation algorithms

## How to Run

1. Open the project folder in your terminal.
2. Run the program:

   Windows and macOS:
   `python main.py`
