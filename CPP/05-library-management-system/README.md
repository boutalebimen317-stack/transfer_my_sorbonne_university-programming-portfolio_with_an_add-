# Library Management System

## About the Project

This is a beginner-level C++ programming project designed to manage books in a small library.

The program allows the users to add books, search for them, borrow and return books, and organize the library collection.

## Features

- Add new books.
- Display all books.
- Search for a book by ID.
- Borrow a book.
- Return a borrowed book.
- Delete books from the library.
- Track book availability.

## Technologies Used

- C++ Programming Language
- GCC Compiler
- Visual Studio Code

## Programming Concepts

- Variables and data types
- Structures
- Vectors
- Functions
- Loops and conditions
- Searching algorithms
- String manipulation
- References
- Basic object-oriented programming concepts

## How to Run

1. Open the project folder in your terminal.
2. Compile the program:

**Windows:**
```powershell
g++ main.cpp -o library_manager.exe
```

**macOS:**
```bash
clang++ main.cpp -o library_manager
```

3. Run the program:

**Windows:**
```powershell
.\library_manager.exe
```

**macOS:**
```bash
./library_manager
```
