# Graph Algorithms Toolkit

## About the Project

This is a beginner-level C++ programming project designed to create and explore graphs using different graph algorithms.

The program allows users to connect vertices, display graph connections, perform BFS and DFS traversals, and find the shortest path between two vertices.

## Features

- Create a graph with multiple vertices.
- Add connections between vertices.
- Display all graph connections.
- Perform Breadth-First Search (BFS).
- Perform Depth-First Search (DFS).
- Find the shortest path between two vertices.
- Validate user input.

## How to Run

1. Open the project folder in your terminal.

2. Compile the program:

   **Windows:**
   ```powershell
   g++ main.cpp -o graph_toolkit.exe
   ```

   **macOS:**
   ```bash
   clang++ main.cpp -o graph_toolkit
   ```

3. Run the program:

   **Windows:**
   ```powershell
   .\graph_toolkit.exe
   ```

   **macOS:**
   ```bash
   ./graph_toolkit
   ```
