# Huffman File Compression

## About the Project

This is a beginner-level C++ programming project designed to compress and decompress text using the Huffman Coding algorithm.

The program analyzes character frequencies, builds a Huffman tree, generates binary codes, and restores the original text from the compressed data.

## Features

- Count character frequencies.
- Build a Huffman tree.
- Generate binary codes for characters.
- Compress text using Huffman Coding.
- Save compressed data to a file.
- Load compressed data from a file.
- Decompress the saved data.
- Save the restored text to a file.

## How to Run

1. Open the project folder in your terminal.

2. Compile the program:

   **Windows:**
   ```powershell
   g++ main.cpp -o huffman.exe
   ```

   **macOS:**
   ```bash
   clang++ main.cpp -o huffman
   ```

3. Run the program:

   **Windows:**
   ```powershell
   .\huffman.exe
   ```

   **macOS:**
   ```bash
   ./huffman
   ```
