# Binary Search Tree Toolkit

## About the Project

This is a beginner-level C++ programming project designed to manage and explore a Binary Search Tree (BST).

The program allows users to insert, search, and delete values, as well as display different tree traversals and find the minimum and maximum values.

## Features

- Insert new values into the tree.
- Search for a specific value.
- Delete a value from the tree.
- Display Inorder traversal.
- Display Preorder traversal.
- Display Postorder traversal.
- Find the minimum value.
- Find the maximum value.

## How to Run

1. Open the project folder in your terminal.
2. Compile the program:

**Windows:**
```powershell
g++ main.cpp -o bst_toolkit.exe
```

**macOS:**
```bash
clang++ main.cpp -o bst_toolkit
```

3. Run the program:

**Windows:**
```powershell
.\bst_toolkit.exe
```

**macOS:**
```bash
./bst_toolkit
```
