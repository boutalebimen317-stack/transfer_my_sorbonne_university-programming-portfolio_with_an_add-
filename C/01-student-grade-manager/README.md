
# Student Grade Management System

## About the Project

This is a beginner-level C programming project designed to manage student information and academic grades.

The program allows users to add students, calculate their averages, search for students, and organize their results.

## Features

- Add new students.
- Display all students.
- Calculate student averages.
- Find the highest and lowest averages.
- Search for a student by name.
- Sort students by average.

## Technologies Used

- C Programming Language
- GCC Compiler
- Visual Studio Code

## Programming Concepts

- Variables and data types
- Arrays and structures
- Functions
- Loops and conditions
- Searching algorithms
- Bubble Sort

## How to Run

1. Open the project folder in your terminal.
2. Compile the program:

   gcc main.c -o student_manager.exe

3. Run the program:

   ./student_manager.exe
