# Mini Shell Interpreter

## About the Project

This is a beginner-level C programming project designed to simulate a simple command-line shell.

The program allows users to enter commands, display available options, clear the terminal, and execute system commands.

## Features

- Display a welcome message.
- Display available commands.
- Clear the terminal screen.
- Display the current date and time.
- Execute system commands.
- Handle empty input.
- Exit the mini shell.

## Technologies Used

- C Programming Language
- GCC Compiler
- Visual Studio Code

## Programming Concepts

- Variables and data types
- Character arrays and strings
- Functions
- Loops and conditions
- String manipulation
- Input handling
- Preprocessor directives
- System command execution

## How to Run

1. Open the project folder in your terminal.
2. Compile the program:

**Windows:**
```powershell
gcc main.c -o mini_shell.exe
```

**macOS:**
```bash
clang main.c -o mini_shell
```

3. Run the program:

**Windows:**
```powershell
.\mini_shell.exe
```

**macOS:**
```bash
./mini_shell
```
