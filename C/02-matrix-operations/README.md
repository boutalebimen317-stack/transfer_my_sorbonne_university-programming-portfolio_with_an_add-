# Matrix Operations Toolkit

## About

A menu-driven C application that performs common mathematical operations on matrices. This project explores two-dimensional arrays, nested loops, functions, and matrix algorithms.

## Features

- Read and display matrices.
- Add two matrices.
- Subtract two matrices.
- Calculate the transpose.
- Multiply two matrices.
- Calculate the main diagonal sum of a square matrix.

## Technologies

- Language: C
- Compiler: GCC
- IDE: Visual Studio Code

## Concepts Practiced

- Two-dimensional arrays
- Nested loops
- Functions and function parameters
- Conditional statements
- Switch statements
- Matrix algorithms
- Input validation

## How to Run

Compile:

```bash
gcc main.c -o matrix_operations
```

Run on Windows:

```powershell
.\matrix_operations.exe
```

## Limitations

- Maximum matrix dimensions: 10 × 10.
- Matrix elements are integers.
- Each execution performs one selected operation.
