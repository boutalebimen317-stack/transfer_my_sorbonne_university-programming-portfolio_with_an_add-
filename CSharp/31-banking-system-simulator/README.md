# Banking System Simulator

## About the Project

A simple console-based banking system developed in C#. It allows users to create bank accounts and perform basic financial operations.

## Features

- Create bank accounts.
- Display registered accounts.
- Deposit money.
- Withdraw money.
- Check account balances.
- View transaction history.
- Validate account numbers and transaction amounts.

## Technologies Used

- C#
- .NET
- Visual Studio Code

## Programming Concepts

- Classes and objects.
- Constructors.
- Lists and collections.
- Methods.
- Conditional statements.
- Loops.
- Input validation.

## How to Run

1. Open the project folder in a terminal.
2. Run:

   `dotnet run`

## Project Status

First version completed. Account information is stored in memory and resets when the program closes.
