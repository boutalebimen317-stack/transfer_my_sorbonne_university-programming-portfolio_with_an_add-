# Hotel Reservation System

## About the Project

A console-based hotel reservation system developed in C#. It allows users to manage room availability and customer reservations through a simple menu-driven interface.

## Features

- View available rooms.
- Make a room reservation.
- Display all reservations.
- Search for a reservation.
- Cancel a reservation.
- Validate user input.

## Technologies Used

- C#
- .NET
- Visual Studio Code

## Programming Concepts

- Classes and objects.
- Lists and collections.
- Methods.
- Conditional statements.
- Loops.
- Input validation.
- CRUD operations.

## How to Run

1. Open the project folder in a terminal.
2. Run:

   `dotnet run`

## Project Status

First version completed. Reservation information is stored in memory and resets when the program closes.
