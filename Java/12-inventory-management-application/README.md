# Inventory Management Application

## About the Project

This is a beginner-level Java project designed to manage products and their quantities in a small inventory.

The program allows users to add products, display the inventory, search for products, update quantities, and calculate the total inventory value.

## Features

- Add new products.
- Display all products.
- Search for a product by name.
- Update product quantities.
- Calculate the total inventory value.
- Validate quantity and price inputs.

## Technologies Used

- Java
- JDK 21
- Visual Studio Code

## Programming Concepts

- Arrays
- Loops
- Conditional statements
- Methods
- Scanner input
- Basic input validation

## How to Run

1. Open the project folder in your terminal.
2. Compile the program:

   Windows and macOS:
   `javac Main.java`

3. Run the program:

   Windows and macOS:
   `java Main`
