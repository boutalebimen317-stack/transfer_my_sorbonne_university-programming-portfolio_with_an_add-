# University Management System

## About the Project

This is a beginner-level Java programming project designed to manage student records in a university.

The program allows users to register students, display their information, search by student ID, update records, and delete students.

## Features

- Add new students.
- Display all registered students.
- Search for a student by ID.
- Update student information.
- Delete student records.
- Prevent duplicate student IDs.
- Validate user input.

## Technologies Used

- Java Programming Language
- JDK
- Visual Studio Code

## Programming Concepts

- Variables and data types
- Classes and objects
- Constructors
- Methods
- ArrayLists
- Loops and conditions
- Searching
- Switch statements
- Exception handling
- Object-oriented programming

## How to Run

1. Open the project folder in your terminal.

2. Compile the program:

   **Windows:**
   ```powershell
   javac Main.java
   ```

   **macOS:**
   ```bash
   javac Main.java
   ```

3. Run the program:

   **Windows and macOS:**
   ```bash
   java Main
   ```
