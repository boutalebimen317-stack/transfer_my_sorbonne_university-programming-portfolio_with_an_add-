# Examination Scheduling System

## About the Project

This is a beginner-level Java project designed to help universities organize their examination schedules.

The program allows users to add exams, display all scheduled exams, and search for a specific exam by its subject name.

## Features

- Add new exams.
- Store subject names, dates, times, and room numbers.
- Display all scheduled exams.
- Search for an exam by subject name.
- Handle invalid menu choices.
- Exit the program safely.

## Technologies Used

- Java
- JDK 21
- Visual Studio Code

## Programming Concepts

- Variables and data types.
- Arrays.
- Methods and functions.
- Loops (`do-while` and `for`).
- Conditional statements (`if` and `switch`).
- User input with Scanner.
- String comparison.

## How to Run

1. Open the project folder in your terminal.

2. Compile the program:

   **Windows:**
   ```bash
   javac Main.java
   ```

   **macOS:**
   ```bash
   javac Main.java
   ```

3. Run the program:

   **Windows:**
   ```bash
   java Main
   ```

   **macOS:**
   ```bash
   java Main
   ```
