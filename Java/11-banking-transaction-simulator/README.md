# Banking Transaction Simulator

## About the Project

This is a beginner-level Java project that simulates a simple banking system.

The program allows users to check their account balance, deposit money, withdraw money, and count successful transactions.

## Features

- Check the current account balance.
- Deposit money into the account.
- Withdraw money from the account.
- Prevent invalid deposits and withdrawals.
- Prevent withdrawals when the balance is insufficient.
- Count successful transactions.
- Display a simple interactive menu.

## Technologies Used

- Java
- JDK 21
- Visual Studio Code

## Programming Concepts

- Variables and data types.
- Methods and functions.
- Conditional statements (`if`, `else if`, `else`).
- Loops (`do-while`).
- Switch statements.
- User input with Scanner.
- Basic arithmetic operations.

## How to Run

1. Open the project folder in your terminal.

2. Compile the program:

   **Windows:**
   ```bash
   javac Main.java
   ```

   **macOS:**
   ```bash
   javac Main.java
   ```

3. Run the program:

   **Windows:**
   ```bash
   java Main
   ```

   **macOS:**
   ```bash
   java Main
   ```
